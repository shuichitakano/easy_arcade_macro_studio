# Sample profiles

Run `npm run generate:samples` to rebuild the generated `.eamacro` files from their reviewed recipe definitions.

## Street Fighter II′: Champion Edition

This is an unofficial command sample for the 1992 arcade game. It contains 12 character macro sets and 37 command sequences.

- Outputs A–F are assumed to be LP, MP, HP, LK, MK, and HK.
- G, I, and K run the first three assigned commands while facing right.
- H, J, and L run the same commands with horizontal mirroring while facing left.
- Additional character commands remain available in the macro list for manual assignment.
- Charge, mash, jump, and simultaneous-button timing is provisional and must be tested on the target board.
